# Expense Tracker

A simple browser-based expense tracker built with HTML, CSS, and JavaScript.

## Features

- Add expenses with a description, amount, category, and date
- View total expenses across all time and for the current month
- Visual breakdown of spending by category
- Filter expenses by category or month
- Delete individual entries or clear all
- Data is saved in the browser using `localStorage`

## Categories

Food, Transport, Housing, Healthcare, Education, Entertainment, Shopping, Utilities, Other

## How to Run

Just open `index.html` in any browser. No setup or installation needed.

## Project Structure

```
expense-tracker/
├── index.html   # Page structure and layout
├── style.css    # Styling
└── app.js       # All logic (add, delete, filter, render)
```
